# 行為金融學：卡尼曼、特沃斯基與塔勒的投資心理學

## 概覽

傳統金融學建立在一個假設之上：人是理性的。理性人會根據所有可得資訊做出最優決策，最大化自身效用。但現實的投資者——包括最聰明的機構投資者——並不是這樣運作的。

行為金融學（Behavioral Finance）的興起，源於心理學家丹尼爾·卡尼曼（Daniel Kahneman）與阿莫斯·特沃斯基（Amos Tversky）從1970年代開始的一系列實驗。他們系統性地記錄了人類判斷與決策的偏差模式，挑戰了標準經濟學的理性人假設。

理查德·塔勒（Richard Thaler）則將這些心理學洞見應用於金融市場，解釋了一系列傳統理論無法說明的「市場異象」（Market Anomalies）。卡尼曼於2002年、塔勒於2017年先後獲得諾貝爾經濟學獎。

**對投資者的根本意義：**

1. **你自己有偏差**：即使你知道這些偏差，也無法完全消除它們，但可以建立系統和流程來緩解
2. **別人也有偏差**：市場參與者的系統性偏差製造了可以被有紀律的投資者利用的機會

## 前景理論：損失厭惡的數學

### 期望效用理論的問題

傳統效用理論（馮·諾伊曼-摩根斯坦）假設人們以財富的最終狀態來評估選擇，以一個凹型效用函數描述風險厭惡。

卡尼曼和特沃斯基的實驗卻發現，人們的實際選擇系統性地違反這個模型。典型例子：

**問題A（確定vs不確定，盈利框架）：**
- 選項1：確定獲得3,000港元
- 選項2：80%機率獲得4,000港元，20%機率一無所獲

大多數人選擇確定的3,000元（雖然選項2的期望值更高：3,200元）。

**問題B（確定vs不確定，虧損框架）：**
- 選項1：確定損失3,000港元
- 選項2：80%機率損失4,000港元，20%機率完全不損失

大多數人選擇風險性的選項2（雖然期望損失更大：3,200元）。

這個「反射效應」（Reflection Effect）說明：人們**在盈利時厭惡風險，在虧損時追逐風險**。

### 前景理論的S型價值函數

卡尼曼和特沃斯基的前景理論（Prospect Theory）用一個S型價值函數來描述這種行為：

```
       價值 ↑
           /
          /  （盈利區域：凹型，邊際遞減）
- - - - -/- - - - → 收益/損失
        /\
       /  \
          \  （虧損區域：凸型，邊際遞減）
           \↓
```

**四個關鍵特徵：**

1. **參照點依賴（Reference Dependence）**：價值評估基於相對變化（相對於某個參照點），而非絕對財富水平
2. **損失厭惡（Loss Aversion）**：損失的痛苦約是同等金額盈利喜悅的2至2.5倍
3. **盈利區域的風險厭惡**：對盈利的邊際效用遞減（「快樂」增加越來越慢）
4. **虧損區域的風險追求**：對虧損的邊際效用也遞減（「痛苦」增加越來越慢，但起點更陡）

## 認知偏差的分類

卡尼曼在《思考，快與慢》（*Thinking, Fast and Slow*）中將人類思維分為「系統一」（直覺、快速、自動）和「系統二」（分析、緩慢、費力）。多數認知偏差源於系統一的捷徑（啟發式）在複雜情境中的應用失誤。

### 錨定效應（Anchoring）

**描述：** 人們過度依賴第一個接收到的資訊（「錨」）來做判斷。

**投資中的表現：**
- 以買入價作為「錨」：「我要等回到成本價才賣」（無論基本面如何變化）
- 以52周高位作為錨：「這股票已跌了50%，很便宜了」（忽略基本面惡化）
- 分析師目標價作為錨：投資者的估值評估往往圍繞分析師目標價而非獨立計算

### 可得性啟發（Availability Heuristic）

**描述：** 人們根據資訊的「可得性」（即多容易想到）來判斷事件的概率，而非根據統計基礎率。

**投資中的表現：**
- 大跌之後過度高估尾部風險（剛剛發生過，所以記憶鮮明）
- 最近表現好的行業被高估（科技股泡沫、加密熱潮）
- 過度關注媒體報道的個股（不等於最佳投資機會）

### 過度自信（Overconfidence）

**描述：** 人們系統性地高估自己判斷的準確性和能力。

**實驗結果：**
- 當人們說自己有90%信心時，他們實際上只有約70%的正確率
- 約80%的司機認為自己比平均水平好

**投資中的表現：**
- 過度交易（每次交易都以為自己有信息優勢）
- 持倉過度集中（對特定判斷過於確信）
- 低估下行風險

### 代表性啟發（Representativeness Heuristic）

**描述：** 人們根據某事物與某個「原型」的相似程度來判斷其概率，忽略基礎率。

**投資中的表現：**
- 看到「故事完美的公司」就認為一定是好投資（忽略估值）
- 連續幾季增長後預測增長永遠持續（忽略均值回歸）
- 「這家公司就像年輕時的蘋果」——代表性類比導致過高估值

## 市場異象：價值溢價與動量效應

行為金融學的一個重要貢獻是解釋傳統資產定價理論（如CAPM）無法解釋的持久性超額回報。

### 價值溢價（Value Premium）

法瑪（Fama）和費倫奇（French）記錄了一個長期存在的現象：低估值股票（低市盈率、低市淨率）長期跑贏高估值股票，超額回報難以用風險完全解釋。

**行為解釋（塔勒和謝弗林）：**

投資者對增長型公司過度外推近期增長，對困境公司過度外推近期虧損。這種「過度反應」（Overreaction）使成長股被高估、價值股被低估。當現實均值回歸時，價值股跑贏。

### 動量效應（Momentum Effect）

與上述價值溢價看似矛盾的是，過去3-12個月表現好的股票，往往在未來3-12個月繼續跑贏（趨勢持續）。

**行為解釋（反應不足理論）：**

投資者對新資訊更新緩慢（反應不足/Underreaction）：當一家公司發布好消息，股價的反應沒有完全反映其長期影響，資訊慢慢「滲入」市場，形成動量效應。

## 處置效應與過度交易

### 處置效應（Disposition Effect）

**定義：** 投資者傾向於過快出售盈利的股票（「鎖定利潤」），同時持有虧損的股票太長時間（「等待回本」）。

這是前景理論的直接應用：在盈利區域的風險厭惡使投資者急於「確認」利潤；在虧損區域的風險追求使投資者拒絕實現損失，賭一個反彈。

**後果：**
- **持有太長的輸家**：繼續惡化，稅務效率差（無法利用虧損抵銷稅款）
- **過早賣出贏家**：錯過後續的複利效應（研究顯示被賣出的贏家往往繼續跑贏）

### 過度交易（Overtrading）

泰倫斯·奧丁（Terrance Odean）研究了數萬個散戶賬戶，發現：**交易頻率最高的賬戶，扣除交易成本後的回報最差**。

交易成本（包括買賣差價、印花稅、市場衝擊）加上過度自信導致的選股失誤，使過度交易者的回報顯著低於被動持有策略。

## 投資者的啟示

**1. 建立系統對抗自身偏差**

由於偏差是自動的、往往是無意識的，僅靠「提醒自己」效果有限。更有效的方法是建立投資流程：
- **投資前：** 寫下買入邏輯及「何種情況意味著你錯了」
- **持倉中：** 定期重新評估，假設你從未持倉：「現在你會買入嗎？」
- **賣出時：** 賣出的原因是否與買入邏輯有關，還是情緒驅動？

**2. 利用處置效應的反面**

市場上存在大量因處置效應而被低估的被拋售後仍然強勢的股票（其他人過早賣出），以及被不合理持有的輸家（等待回本的賣壓一旦解除就會繼續下跌）。識別這些情況是超額回報的來源之一。

**3. 損失厭惡的再框架**

意識到自己對損失的痛苦是同等盈利喜悅的2倍以上，可以主動調整風險管理：
- 不要因為虧損讓你「感覺更差」而任意改變持倉計劃
- 理性計算期望值，而不是情緒性反應

**4. 價值與動量的結合**

學術研究顯示，同時利用價值因子和動量因子可以獲得穩定的超額回報：
- 在低估值（價值因子）的股票中，選擇有正動量（近期業績改善）的
- 避免「價值陷阱」：低估值但動量持續負面，往往是基本面惡化的訊號

**5. 錨定效應的應對**

分析任何資產時，主動忽略當前市價，從基本面重新估算內在價值；比較自己的獨立估算與市場共識，識別差異的來源。
