# 因子模型：系統性風險如何驅動橫截面回報（第二講）

## 概覽

為什麼兩個股票在同一個市場上，長期回報會相差一倍甚至更多？為什麼小市值公司平均比大市值公司回報更高？為什麼廉價股（低P/B）的回報歷史上優於貴價股？

**因子模型（Factor Models）** 試圖系統性地回答這些問題。它的核心主張是：資產回報不是隨機的，而是由少數可識別的「系統性風險因子」驅動。你的組合持有什麼，從根本上決定了你承擔了什麼風險、預期獲得什麼回報。

從單因子的CAPM，到Fama-French三因子，再到今日的多因子框架，因子模型的演進反映了我們對橫截面回報差異理解的不斷深化。對投資者而言，理解因子暴露是理解「我的錢真正在做什麼」的基礎。

## CAPM：單因子世界

### 理論框架

資本資產定價模型（CAPM）由Sharpe（1964）、Lintner（1965）和Mossin（1966）獨立提出，建立在馬科維茨均值方差框架上，是現代金融的基石。

**CAPM方程：**

$$E[r_i] = r_f + \beta_i \cdot (E[r_M] - r_f)$$

其中：
- $E[r_i]$ = 資產 $i$ 的預期回報
- $r_f$ = 無風險利率
- $\beta_i$ = 資產 $i$ 的系統性風險係數
- $E[r_M] - r_f$ = 市場風險溢價（Market Risk Premium, MRP）

**Beta的定義：**

$$\beta_i = \frac{Cov(r_i, r_M)}{Var(r_M)}$$

Beta衡量資產回報對市場回報的敏感性：Beta = 1表示與市場同步；Beta = 1.5表示市場漲10%時資產預期漲15%（跌時亦然）；Beta = 0.5表示半個市場的波動。

### 系統性風險 vs 特質風險

CAPM將資產的總風險分解為兩部分：

$$\sigma_i^2 = \beta_i^2 \sigma_M^2 + \sigma_{\varepsilon,i}^2$$

- **系統性風險（Systematic Risk）**：$\beta_i^2 \sigma_M^2$，由市場整體波動驅動，無法通過分散化消除，因此投資者要求補償
- **特質風險（Idiosyncratic Risk）**：$\sigma_{\varepsilon,i}^2$，個股特有的隨機擾動，在充分分散的組合中相互抵消，因此不應獲得風險溢價

這個分解產生了深遠的含義：**投資者只應為承擔系統性風險（Beta）獲得補償，而非為承擔特質風險獲得補償。** 如果你沒有分散化你的組合，而是集中持有少數股票，你承擔了大量特質風險，但市場不會為此補償你。

### CAPM的局限

CAPM在理論上優美，但實證表現令人失望。研究顯示：

- 高Beta股票並未如預測的那樣提供更高回報（Beta平面化，甚至低Beta超額回報）
- 有大量橫截面回報差異無法用Beta解釋
- 市場組合（所有可投資資產的組合）在實踐中不可觀測，Roll批判指出CAPM測試本質上是不可測試的

這些實證失敗催生了多因子模型的發展。

## Fama-French三因子：規模與價值

### 兩個新異常的發現

Eugene Fama和Kenneth French在1992-1993年的研究中記錄了兩個CAPM無法解釋的橫截面回報模式：

**規模效應（Size Effect）：** 小市值股票（小市值的底部30%，SMB組合中的「Small」部分）長期跑贏大市值股票（大市值的頂部30%，「Big」部分）。

**價值效應（Value Effect）：** 高賬面市值比股票（HML組合中的「High」，即價值股）長期跑贏低賬面市值比股票（「Low」，即成長股）。

### 三因子模型

Fama-French三因子模型（1993）：

$$E[r_i] - r_f = \alpha_i + \beta_i(r_M - r_f) + s_i \cdot SMB + h_i \cdot HML$$

其中：
- **SMB（Small Minus Big）**：每月小市值股票組合回報減去大市值股票組合回報
- **HML（High Minus Low）**：每月高賬面市值比股票組合回報減去低賬面市值比股票組合回報
- $s_i$：資產 $i$ 對SMB因子的暴露（正值表示偏向小市值）
- $h_i$：資產 $i$ 對HML因子的暴露（正值表示偏向價值）

若 $\alpha_i$（截距）接近零，三因子模型很好地解釋了資產 $i$ 的回報。若 $\alpha_i$ 顯著正或負，說明有三因子無法解釋的超額回報（或不足）。

### 經濟學解釋：風險還是錯誤定價？

關於規模和價值溢價的來源，存在兩種對立解釋：

**風險補償視角（Fama-French的解讀）：**
小公司和高賬面市值比公司面臨更高的財務困境風險（Distress Risk），投資者要求更高回報作為補償。SMB和HML是「隱性風險因子」的代理。

**行為金融視角（Lakonishok等的解讀）：**
投資者系統性地過度外推成長股的高增長，導致其估值過高；同時對困境股過度悲觀，導致其估值過低。當現實修正預期時，價值股回報更高——這是行為偏差，而非風險溢價。

這個辯論至今未有定論。但無論解釋如何，**溢價的存在已被廣泛複製於全球多個市場**。

## 多因子框架的演進

### 動量因子（WML）

Jegadeesh和Titman（1993）記錄了**動量效應（Momentum Effect）**：過去3-12個月表現最好的股票，在未來3-12個月內繼續跑贏市場；過去表現最差的股票繼續跑輸。

**WML（Winners Minus Losers）因子** 衡量動量溢價：買入過去12個月（跳過最後1個月）表現最好的前10%股票，同時做空表現最差的後10%股票。

動量因子的特殊性：
- 它與價值因子通常呈**負相關**（動量股往往不便宜）——兩者組合提供良好的分散化
- 它有**崩潰風險（Crash Risk）**：在急跌後的急速反彈（如2009年3月）中，動量策略可以在數天內損失20-30%
- 行為解釋更有說服力（過度反應、投資者注意力偏差）

### Fama-French五因子

Fama和French在2015年將模型擴展至五個因子，加入：

**RMW（Robust Minus Weak）**：高盈利能力（ROE）股票相對低盈利能力股票的回報差異，代表**盈利能力因子**。

**CMA（Conservative Minus Aggressive）**：低資本支出（保守投資）公司相對高資本支出（激進擴張）公司的回報差異，代表**投資保守性因子**。

五因子模型：

$$E[r_i] - r_f = \alpha_i + \beta_i MKT + s_i SMB + h_i HML + r_i RMW + c_i CMA$$

五因子模型的覆蓋力顯著高於三因子模型，但也消除了部分HML效應（盈利能力和投資因子能解釋部分價值溢價）。

### 機構因子模型：Barra和Axioma

學術因子模型與機構使用的商業風險模型（如MSCI Barra、Axioma）存在差異：

**學術模型特點：**
- 長-短多空因子，純粹測量因子溢價
- 主要用於解釋歷史回報和歸因分析

**商業風險模型特點：**
- 50-100個因子，包括行業、風格、國家因子
- 主要用於風險預測（協方差矩陣估計）和組合優化
- 特別注重因子之間的正交性（避免多重共線性）
- 提供日頻更新的因子暴露

## 因子暴露的測量與分解

### 時序回歸法

最直接的方法是對資產 $i$ 的回報進行時序回歸：

$$r_{i,t} - r_{f,t} = \alpha_i + \beta_i f_{MKT,t} + s_i f_{SMB,t} + h_i f_{HML,t} + \varepsilon_{i,t}$$

回歸係數 $(\beta_i, s_i, h_i)$ 即為資產的因子暴露（Factor Loadings）。$R^2$ 表示模型解釋的回報方差比例。對大市值股票，三因子模型通常能解釋60-80%的回報方差。

### 組合的回報歸因

對整個組合，回報可以分解為：

$$r_{portfolio} = r_f + \sum_{k} \hat{\beta}_{k} f_k + \alpha + \varepsilon$$

- **因子回報貢獻**：$\sum_{k} \hat{\beta}_{k} f_k$（已知風險因子的暴露帶來的回報）
- **Alpha**：$\alpha$（超越所有已知因子的超額回報，真正的選股/擇時能力）
- **殘差**：$\varepsilon$（未被模型捕捉的隨機成分）

這個分解對評估基金經理非常重要：許多標榜自己能產生Alpha的基金，實際上只是增加了對價值或動量因子的暴露。在控制因子暴露後，真正的Alpha所剩無幾。

### 橫截面風險分解

商業風險模型將組合的總風險（方差）分解為：

$$\sigma_p^2 = \mathbf{x}^T \mathbf{F} \mathbf{f} \mathbf{F}^T \mathbf{x} + \mathbf{x}^T \boldsymbol{\Delta} \mathbf{x}$$

其中前項是**系統性風險（因子風險）**，後項是**特質風險**（$\boldsymbol{\Delta}$ 是特質方差的對角矩陣）。

這個分解讓投資組合經理知道：組合中有多少風險來自市場Beta、有多少來自行業集中度、有多少來自風格因子、有多少是個股特質風險。這是專業風險管理的基礎。

## 投資者的啟示

### 理解你組合的真實風險敞口

大多數普通投資者認為自己選的是「好股票」，但實際上，他們的回報在很大程度上由因子暴露決定：

- 持有很多科技股 = 大量成長因子（負HML）+ 大量動量因子（過去表現好）
- 持有銀行股 = 大量價值因子（低P/B）+ 大量金融行業敞口
- 持有小型港股 = 大量規模因子（SMB）+ 港股市場因子

若你的因子暴露能解釋大部分組合回報，那你沒有必要支付高昂的主動管理費——因子ETF可以以更低成本實現相同暴露。

### 因子擇時 vs 因子收割

**因子擇時（Factor Timing）：** 根據對因子溢價的預測，動態調整各因子的暴露——例如在價值便宜時超配價值，在動量信號強時超配動量。

**因子收割（Factor Harvesting）：** 長期、系統性地持有對多個因子的正面暴露，不做擇時，通過廣度和時間分散化收穫長期溢價。

研究顯示，因子擇時非常困難，大多數投資者無法持續預測哪個因子即將表現好。**長期堅持多因子暴露（因子收割），並在表現不佳時保持紀律，通常優於頻繁的因子輪換**。

理解因子模型的最大價值，不是要人人都建構複雜的多因子組合，而是讓投資者知道他們實際上在承擔什麼風險、為什麼得到（或得不到）相應的回報。
