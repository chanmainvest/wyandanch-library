# 差分機器學習：自動微分與神經網絡定價

## 概覽

機器學習在金融領域的應用通常分為兩類：一類是預測類應用（預測市場方向、信用評分、異常交易偵測），另一類是定價類應用（用神經網絡近似複雜衍生品的定價函數）。**差分機器學習（Differential Machine Learning）** 屬於後者，是近年來量化金融最令人興奮的方法論創新之一。

傳統的衍生品定價方法——蒙特卡洛模擬、有限差分法（PDE方法）——在高維問題（如多資產組合期權、路徑依賴型商品衍生品）中面臨「維度詛咒（Curse of Dimensionality）」：計算複雜度隨維度指數增長。神經網絡作為通用函數逼近器，天然適合近似高維函數，規避了維度詛咒。

**差分機器學習的核心創新：** 訓練神經網絡時，不僅使用期權價格 $V$ 作為訓練目標，還同時使用期權對輸入變量（如標的資產價格 $S$、波動率 $\sigma$ 等）的偏導數（即「希臘字母」）作為訓練目標。這樣做不僅加速了訓練，還顯著提高了網絡在定價和對沖方面的精度和樣本效率。

## 自動微分：計算梯度的引擎

### 自動微分 vs 符號微分 vs 數值微分

在深入差分機器學習之前，需要理解**自動微分（Automatic Differentiation, AD）**——深度學習的核心計算引擎。

**符號微分（Symbolic Differentiation）：** 手工推導或用計算機代數系統（如Mathematica）求解析微分公式。精確但只適用於有封閉形式的函數，對複雜計算圖不可行。

**數值微分（Numerical Differentiation）：** 用有限差分近似：
$$\frac{\partial f}{\partial x} \approx \frac{f(x + \epsilon) - f(x)}{\epsilon}$$
簡單，但存在截斷誤差（$\epsilon$ 太大）和舍入誤差（$\epsilon$ 太小），且對 $n$ 維輸入需要 $n$ 次額外的函數評估。

**自動微分（AD）：** 利用**鏈式法則（Chain Rule）** 在計算過程中精確計算梯度，無截斷誤差，計算效率高。AD是所有現代深度學習框架（PyTorch、JAX、TensorFlow）的基礎。

### 前向模式 vs 反向模式

自動微分有兩種主要模式：

**前向模式（Forward Mode AD）：**
從輸入到輸出正向計算，同時追蹤每個中間變量對某個輸入的偏導數。對計算單個輸入對所有輸出的梯度有效（即 $\frac{\partial \mathbf{y}}{\partial x_i}$）。

對 $f: \mathbb{R}^n \to \mathbb{R}^m$，計算全梯度需要 $n$ 次前向傳播。

**反向模式（Reverse Mode AD）：**
先正向計算記錄計算圖，再從輸出到輸入反向傳播梯度。對計算「一個輸出對所有輸入」的梯度有效（即 $\frac{\partial y}{\partial \mathbf{x}}$）。

對 $f: \mathbb{R}^n \to \mathbb{R}$（$m = 1$，如損失函數），反向模式只需**一次反向傳播**即可計算對所有 $n$ 個輸入的梯度。這就是深度學習中「反向傳播（Backpropagation）」的本質——它是反向模式AD的特殊情況。

**在差分機器學習中的應用：** 計算期權價格的希臘字母（如 $\partial V/\partial S$、$\partial V/\partial \sigma$ 等），即是計算標量輸出（價格）對向量輸入（市場變量）的梯度——完全適合反向模式AD，可以一次性計算所有希臘字母。

### PyTorch和JAX的AD實現

**PyTorch示例：**
```python
import torch

# 定義輸入，requires_grad=True追蹤梯度
S = torch.tensor(100.0, requires_grad=True)  # 標的價格
sigma = torch.tensor(0.2, requires_grad=True)  # 波動率

# Black-Scholes Call定價（簡化版）
d1 = (torch.log(S/100) + 0.5*sigma**2) / sigma
price = S * torch.distributions.Normal(0,1).cdf(d1) - 100 * torch.distributions.Normal(0,1).cdf(d1 - sigma)

# 一次反向傳播計算Delta和Vega
price.backward()
delta = S.grad    # ∂V/∂S
vega = sigma.grad  # ∂V/∂σ
```

**JAX** 的函數式自動微分更適合差分機器學習——`jax.grad`、`jax.jacobian`、`jax.hessian` 可以任意組合，支持計算高階導數（如Gamma = $\partial^2 V / \partial S^2$）。

## 差分神經網絡：利用希臘字母信息

### 核心思想

標準神經網絡訓練使用 $(x_i, y_i)$ 數據對，其中 $y_i = V(x_i)$ 是期權價格。若訓練數據來自蒙特卡洛模擬，計算每個路徑的期權價值已知，但在高維問題中，需要大量路徑才能獲得精確估計。

**差分神經網絡的關鍵洞察：** 在每個訓練點，不僅可以計算期權價格 $V(x)$，還可以使用**路徑微分（Pathwise Differentiation）**計算 $\frac{\partial V}{\partial x}$——對蒙特卡洛路徑，這幾乎不需要額外計算（只需對已有的路徑求微分）。

因此，差分神經網絡的訓練集是 $(x_i, y_i, \frac{\partial y_i}{\partial x_i})$，包含了目標函數及其梯度信息。

### Sobolev訓練：損失函數的設計

**Sobolev訓練（Sobolev Training）** 是差分機器學習的損失函數設計：

$$\mathcal{L} = \underbrace{\lambda_0 \sum_i (V(x_i; \theta) - y_i)^2}_{\text{價格損失}} + \underbrace{\lambda_1 \sum_i \left\|\frac{\partial V(x_i; \theta)}{\partial x_i} - \frac{\partial y_i}{\partial x_i}\right\|^2}_{\text{希臘字母損失}}$$

其中 $\theta$ 是神經網絡的參數，$\lambda_0$ 和 $\lambda_1$ 是權衡係數（通常 $\lambda_1$ 遠大於 $\lambda_0$，因為每個訓練點提供多個希臘字母目標，信息量更大）。

**效率提升的直覺：** 對一個輸入維度為 $n$ 的問題，每個訓練樣本除了提供1個價格目標外，還提供了 $n$ 個梯度目標。若 $n = 10$，每個樣本的訊息量增加了10倍，使得在相同準確性下，所需訓練樣本數減少了一個數量級（100-1000倍）。

## 期權定價的神經網絡方法

### 香草期權的神經網絡定價

對簡單的歐式期權，神經網絡定價並無必要（Black-Scholes有解析解）。但它可以作為**基準**驗證差分機器學習框架的正確性：

**輸入特徵：** $(S/K, T, \sigma, r)$（貨幣性、到期時間、波動率、利率）
**目標：** 無量綱化的BSM期權價格 $C/K$（確保網絡輸出尺度獨立）
**希臘字母目標：** $\partial(C/K) / \partial(S/K) = \Delta$，$\partial(C/K)/\partial\sigma = \nu/K$

驗證：訓練後的網絡應在整個輸入空間準確複製BSM定價，且Delta、Vega的輸出應與BSM解析解吻合。

### 奇異期權與高維問題

差分機器學習的真正優勢在**奇異期權（Exotic Options）和高維問題**上：

**百慕大期權（Bermudan Options）：** 允許在有限個提前執行日執行，沒有封閉解。蒙特卡洛定價需要解一個倒向隨機微分方程（BSDE），差分神經網絡可以同時學習定價函數和最優執行邊界。

**多資產籃子期權（Basket Options）：** 標的資產數量增至10、20甚至100個，傳統有限差分法面臨維度詛咒（100維PDE），蒙特卡洛法需要大量路徑。差分神經網絡在高維問題中收斂顯著快於純粹蒙特卡洛。

**氣候金融衍生品（Weather Derivatives, Climate Risk）：** 以溫度、降水量等為標的的衍生品，其標的動態複雜且數據稀缺，差分神經網絡的樣本效率優勢在此特別顯著。

### 路徑微分：計算希臘字母的有效方法

對蒙特卡洛路徑，**路徑微分（Pathwise Differentiation，又稱 Infinitesimal Perturbation Analysis, IPA）** 是計算蒙特卡洛估計梯度的高效方法：

$$\frac{\partial E[V]}{\partial S_0} = E\left[\frac{\partial V}{\partial S_0}\right]$$

即梯度的期望等於梯度的蒙特卡洛估計，可以在模擬路徑時同時計算梯度，無需額外的「有限差分路徑」。

這個方法在技術上需要目標函數對路徑幾乎處處可微，對大多數標準衍生品（歐式期權、亞式期權）成立，但對數字期權（Digital Options）等非連續payoff需要特殊處理（如Likelihood Ratio Method，LRM）。

## 微分正則化：改善樣本效率

### 為何梯度信息能大幅提升效率

假設你想在二維空間中逼近一個平滑函數。若只有函數值，每個樣本點提供1個約束（函數在該點的值）；若同時有梯度，每個樣本點提供3個約束（函數值、x方向梯度、y方向梯度）。梯度信息的「槓桿效應」使樣本效率倍增。

**在高維問題（如10維期權定價問題）中，** 每個樣本點額外提供10個梯度目標，訓練信息量是純函數值的11倍。理論結果顯示，達到相同逼近精度所需的樣本數可減少 $n^2$ 倍（$n$ 是維度），使差分神經網絡在高維問題中遠勝傳統蒙特卡洛方法。

### 實際的訓練技巧

**希臘字母的標準化：** 不同希臘字母的數量級差異很大（Delta通常0至1，Gamma可能很小，Vega數量級取決於合約規模）。在計算損失函數前，需要將各希臘字母標準化到相近量級，避免梯度損失被一個希臘字母主導。

**自適應權衡係數：** $\lambda_0$ 和 $\lambda_1$ 的相對大小影響訓練結果。可以使用自適應方法在訓練過程中動態調整，確保價格精度和希臘字母精度同時收斂。

**網絡架構選擇：** 對期權定價，常用的激活函數是SELU或ELU（而非ReLU）——因為ReLU的二階導數為零，使Gamma的計算退化。平滑激活函數保留了高階導數信息。

## 投資者的啟示

### ML在量化金融的誇大宣傳 vs 現實

機器學習在量化金融中被過度炒作，很多聲稱使用ML的策略實際上不過是在做更複雜的數據挖掘。以下是一個更清醒的評估框架：

**ML真正有用的場景：**
- **高維衍生品定價：** 路徑依賴型、多資產奇異期權，傳統方法計算量大，ML顯著提速
- **複雜信用組合模擬：** 含多重相關性的信用組合，差分ML在VaR/CVaR計算中有明確優勢
- **非線性特征提取：** NLP處理非結構化數據（新聞、財報文本），圖神經網絡建模供應鏈關係
- **替代數據的特征工程：** 衛星圖像、信用卡數據等非傳統數據的特征提取

**ML局限性明顯的場景：**
- **市場方向預測：** 短期回報的信噪比極低，ML容易過擬合歷史噪聲
- **危機時期的外推：** 深度學習模型在訓練分佈之外（Out-of-Distribution）往往表現很差，危機往往是「從未見過的」環境
- **小數據問題：** 金融數據的時序長度有限（10-30年），高頻模型的參數數量必須嚴格控制

### 差分機器學習的真實價值

差分機器學習是少數幾個在衍生品定價中有清晰的、可量化的效率優勢的ML應用之一：

1. **計算速度：** 訓練後的神經網絡定價速度（微秒級）遠快於蒙特卡洛（分鐘至小時級），對需要實時風險評估（如做市商的日內希臘字母計算）有明確的工程價值

2. **精度：** 在高維問題中，相同計算預算下，差分神經網絡的定價精度顯著高於標準蒙特卡洛

3. **希臘字母一致性：** 標準蒙特卡洛的Delta需要有限差分估計（兩次模擬），噪聲較大；差分神經網絡的Delta直接從反向傳播計算，更穩定

然而，這些優勢僅在正確實施（數據質量、架構設計、訓練穩定性）的情況下才能實現。盲目應用ML而不理解其假設和局限，往往產生比傳統方法更差的結果。

**最終判斷標準：** 一個量化金融中的ML應用是否有真實價值，取決於它是否在**嚴格的樣本外測試**中超越了設計良好的傳統方法，而非僅在訓練集上的表現。差分機器學習在這個嚴格標準下，是為數不多能通過考驗的ML金融應用之一。
